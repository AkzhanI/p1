Skill Tracker (Python/Tkinter)

A desktop application for tracking skills and learning progress through a gamified XP system.

Features:
- Custom categories with configurable XP rules (+2/+5/+7/+10)
- XP and level tracking based on activity history
- Category deletion (history is preserved)
- Scrollable category list (Canvas + Scrollbar)
- Data persistence via JSON (categories.json, history.json)

Technologies:
- Python
- Tkinter
- JSON

Status:
Work in progress.
